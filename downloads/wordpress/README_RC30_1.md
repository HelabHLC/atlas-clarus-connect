# WordPress update: ATLAS Clarus Browser Edition / Colour Projects

[Download the installable WordPress ZIP](ATLAS_Clarus_Browser_Edition_v0.1.15-beta10_RC30.1.zip)

This is **Browser Edition 0.1.15-beta10**, containing **Colour Projects RC30.1**.
Upload this ZIP without extracting it through WordPress **Plugins > Add New >
Upload Plugin**. Replace the installed **ATLAS Clarus Browser Edition**.
Do not delete the existing plugin first.

Then open **Tools > ATLAS Clarus Browser Edition** and choose
**Mitgeliefertes RC30.1 prüfen und aktiv schalten**.
Once **Neues Bundle aktiv: JA** appears, open the application and select
**Colour Projects**. The previous runtime remains available for rollback.

The similarly named **Browser Bundle** ZIP is only for opening `index.html`
directly in a browser. It is not a WordPress plugin.
