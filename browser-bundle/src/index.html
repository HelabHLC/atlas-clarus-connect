Frequently asked questions

IDENTITY FIRST

What is ATLAS Clarus?

An open workflow for finding, understanding, collecting and handing over colour-reference identities without silently redefining their source.

How do I build a palette?

Choose a colour in Hover and select Add to palette. You can create, name, duplicate, sort, import and delete several local palettes. The active palette is shared by Hover and Wheel.

Which exports are included?

ASE for Adobe/Affinity, GPL for GIMP/Inkscape, Figma-compatible Tokens JSON, CSS custom properties and Clarus JSON with identity evidence.

Does an export preserve the identity?

Clarus JSON retains the full reference metadata. Other application formats carry usable names and exact master RGB, but their host applications may not retain every provenance field.

Is the displayed colour physically exact?

No. Screen colour depends on display, profile and viewing conditions. It is a reference representation, not a measured print, textile, coating or production approval.

Does the bundle track users?

No. It runs locally, sends no analytics or colour selections, and stores the shared palette only in this browser's local storage.

What does frozen A′ v0.4 mean?

The established selection and ranking logic is not changed by this browser edition. Interaction Wheel v0.5 adds descriptive diagnostics only.

Is this a Pantone library?

No. Observed source-context views are descriptive and claim no Pantone identity or equivalence. ATLAS references remain independently addressed.
