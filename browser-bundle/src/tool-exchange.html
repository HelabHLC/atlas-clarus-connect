Exchange between tools

Keep complete source files, original RGB, fixed references and history together. Prepare an explicit working view for another tool and bring its edits back into the same package.

A working view can contain fewer editable fields than its source. The complete source stays in the exchange ZIP. PNG, ASE, GPL, CSS, tokens and recipes can be retained unchanged as attachments; that does not make them complete editable projects.
