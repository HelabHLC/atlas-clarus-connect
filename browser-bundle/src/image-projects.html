2. Save and hand over

Your colleague opens the ZIP or image-project JSON in Image Projects. PNG alone does not preserve the full history. A linked palette snapshot can also be opened separately in Colour Projects.

Open an image to start. This workspace is not automatically saved in browser storage.

Edits use browser-decoded 8-bit sRGB. Recolouring applies a flat RGB value and preserves existing opacity; making pixels transparent keeps their earlier RGB values in the project history.

3. Record your edit

Exact matching uses the same RGB numbers, with no tolerance. Similar shades are not automatically included.

Undo and redo add history entries. Earlier edits and removed colours remain recoverable. A new edit after undo keeps the abandoned steps in the journal.
