The ZIP contains RGB swatches, full provenance JSON and a checksum manifest. Keep these files together. The same JSON opens in Colour Kit 0.3.0.

What travels with the colour?

The recorded image name, pixel or area location, available image hash, original RGB, Atlas assignment and later decision revisions stay in the JSON. ASE swatch names link to those records. Hashes check consistency; they do not authenticate authorship.

A native Adobe round trip remains untested. The provenance JSON is a companion file and is not automatically embedded in an Adobe document.
