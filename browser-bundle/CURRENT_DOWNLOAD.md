# Stable browser-bundle download

The homepage should link to this permanent URL:

`https://github.com/HelabHLC/atlas-clarus-connect/releases/download/browser-bundle-current/ATLAS_Clarus_Browser_Bundle_current.zip`

Checksum companion:

`https://github.com/HelabHLC/atlas-clarus-connect/releases/download/browser-bundle-current/ATLAS_Clarus_Browser_Bundle_current.zip.sha256`

After this workflow is merged into `main`, every relevant successful `main` build replaces the two assets in the moving prerelease `browser-bundle-current`. Pull requests, draft branches and failed validations do not change the public download.

The WordPress homepage needs this URL only once. Later browser-bundle versions do not require another page edit.
