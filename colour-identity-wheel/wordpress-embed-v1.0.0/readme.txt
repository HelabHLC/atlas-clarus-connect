Bindet das ATLAS Clarus Reference Wheel responsiv in eine WordPress-Seite ein.

== Installation ==

1. Die ZIP-Datei im WordPress-Backend unter Plugins > Neues Plugin hinzufügen > Plugin hochladen auswählen.
2. Plugin installieren und aktivieren.
3. Eine Seite bearbeiten und einen Shortcode-Block einfügen.
4. Den Shortcode [atlas_clarus_wheel] einsetzen.
5. Seite veröffentlichen.

Die Zieladresse und die Höhen für Desktop und Smartphone können unter Einstellungen > ATLAS Clarus Wheel angepasst werden.

== Shortcode ==

[atlas_clarus_wheel]

Optionale individuelle Höhe:

[atlas_clarus_wheel height="1300" mobile_height="1700"]

== Hinweise ==

Die Anwendung wird aus der veröffentlichten ATLAS-Clarus-Seite geladen. Aktualisierungen der Anwendung erscheinen dadurch automatisch in der WordPress-Einbettung. ICC-Dateien werden innerhalb der Anwendung lokal im Browser verarbeitet.
