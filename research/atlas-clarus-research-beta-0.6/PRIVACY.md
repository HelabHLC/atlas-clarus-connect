# ATLAS Clarus Public Research Beta: data handling

The single HTML application has no analytics, tracking, cookies, persistent browser data storage, remote scripts or automatic network connections. CSV, CxF and CGATS files explicitly chosen by the user are read via the browser File API and processed in memory. Reloading clears the imported data.

**Optional external publisher links:** The Sources & import tab contains ordinary hyperlinks to CIE, freieFarbe and Fogra websites. They are not loaded automatically. Clicking a link makes an independent browser visit to that publisher, which can receive standard network data under its own policies. Nothing from imported files is sent to the publisher or to ATLAS Clarus.

Downloaded JSON and CSV files contain user-selected source spectra and computed results. The user is responsible for their confidentiality and applicable upstream reuse licences. This is not a certified print or colour reproduction tool.
