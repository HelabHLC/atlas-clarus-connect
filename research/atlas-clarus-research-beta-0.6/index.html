Quick start

  1. Import a 36-row spectrum CSV with a “reference” column and optional variants, or generate purely synthetic test curves.
  2. For real Lab and ΔE00 calculations, import your own observer (x̄, ȳ, z̄) and illuminant SPD CSVs.
  3. Use Colour Advisory for comparisons, or Spectral Lab for an experimental constrained fit. Export JSON or CSV.

The synthetic curves are mathematical illustrations, not an HLC colour, a material measurement, or a colourimetric reference.

Only reflectance factors between 0 and 1 are supported by this experimental solver. Fluorescence-related source values above 1 are rejected, not silently clipped. Import does not prove production suitability.

Colour Advisory

Compare imported spectral candidates with your own reference, rank variants across the light sources you supply, and export a traceable assessment.

1 · Import user-owned data

Files are read locally. Use decimal points and 10 nm spacing from 380 through 730 nm. Observer and illuminant files may also be 1 nm tables. Single-illuminant CSVs can be assigned below.

2 · Light priorities

0 = ignore · 1 = normal · 2 = important · 3 = very important. Priorities only affect evaluation and optional spectral optimisation, not any physical light source or printer.

Spectral Lab

Generate an experimental 36-point target spectrum using your imported observer, illuminants and reflectance source. Export the result and its residuals.

3 · Target Lab(D50)

Requires imported reference reflectance, observer functions and D50 spectral power distribution. No values are fetched automatically.

Model and limitations

Constrained numerical fit to the target D50 tristimulus values. Penalties favour similarity to the imported reference, smoothness and lower changes under other weighted illuminants. An XYZ residual may remain; the spectrum is not uniquely determined and may be physically unrealizable.

No analytics, remote processing, cookies, external scripts or embedded proprietary reference datasets.
