# ATLAS Clarus Connect v0.1.0 release approval

**Decision:** APPROVED FOR PUBLIC GITHUB RELEASE  
**Decision date:** 2026-08-31  
**Intended repository:** `HelabHLC/atlas-clarus-connect`  
**Live Wheel deployment:** not included in this approval

The project owner granted the conscious release decision after review of:

- Hover Library v0.1.5 source and data;
- Colour Identity Wheel Sites v22 source provenance;
- strict Identity Handoff validation and eight application tests;
- one valid and eight rejected protocol test vectors;
- GPL-2.0-or-later software licensing;
- CC BY 4.0 documentation licensing;
- zlib data licensing with freieFarbe attribution and modification notice;
- trademark, Pantone and physical-colour claim boundaries.

This approval authorises publication of the repository package. It does not by itself deploy the strict-HLC patch to the public Colour Identity Wheel Site, create an independent certification mark or constitute external legal advice.
