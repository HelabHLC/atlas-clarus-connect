ATLAS Clarus → QuarkXPress

RC34.9 · XPress-Tags-Export · Testfassung

Überträgt bis zu 256 benannte RGB-Farben als .xtg-Datei. Die ATLAS-Adressen und die RGB-Werte bleiben erhalten. Geschützte Originalfarben behalten ihre eigenen Namen und Werte.

1. Aus ATLAS Clarus exportieren

  1. PALETTE → My Palettes öffnen und Referenzen hinzufügen.
  2. QuarkXPress XTG wählen. Alternativ in Colour Reduction → Palette format → QuarkXPress XPress Tags wählen und Download palette anklicken.
  3. Für die vollständigen Referenz- und Ursprungsdaten zusätzlich Clarus JSON bzw. den vollständigen Reduktionsjob sichern. Der Job enthält auch palette.xtg.

2. In QuarkXPress importieren

  1. Für den ersten Test ein neues, leeres Projekt anlegen. So vermeiden Sie Konflikte mit schon vorhandenen, gleichnamigen Farben.
  2. Einen Textrahmen erstellen und den Textcursor darin platzieren.
  3. Datei → Importieren / File → Import wählen und die .xtg-Datei auswählen. Falls nötig den Dateifilter auf Textdateien oder alle Dateien umstellen.
  4. Interpret XPress Tags (XPress Tags interpretieren) aktivieren. Die Kodierung ist UTF-8; sie ist in der Datei als <e9> angegeben.
  5. Die Datei erzeugt eine farbige Textliste und die zugehörigen Farbfelder. Unter Bearbeiten → Farben / Edit → Colors Namen und RGB-Werte kontrollieren.

3. sRGB als Quellprofil verwenden

Die XTG-Datei enthält RGB-Zahlen, aber kein eingebettetes ICC-Profil. Unter Edit → Color Setups → Source für RGB-Volltonfarben / RGB solid colours das Profil sRGB IEC61966-2.1 verwenden und diese Quelleinstellung im Projekt auswählen. „Solid colours“ bezeichnet hier die im Layout angelegten Farben. Die exportierten Farben sind RGB-Prozessfarben, keine Sonderfarben.

Kontrollbeispiel

H075_L060_C045 muss als RGB 180 / 136 / 67 erscheinen (#B48843). Die mitgelieferte Testdatei enthält dieses und weitere Farbfelder; ihre Vergleichswerte stehen in examples/QUARKXPRESS_EXPECTED.json.

Bei bereits vorhandenen gleichnamigen Farben kann QuarkXPress einen Namenskonflikt melden oder vorhandene Definitionen verwenden. Prüfen Sie die Werte erneut, bevor Sie die Farben in ein bestehendes Projekt übernehmen.

Prüfstatus: Der Export folgt dem offiziellen XPress-Tags-Handbuch. Dateistruktur, RGB-Zahlen und Farbnamen werden geprüft. Der tatsächliche Import in einer installierten QuarkXPress-Version ist noch offen. Die Dokumentation richtet sich nach QuarkXPress 2026; ältere Versionen sind nicht zugesichert. Eine Farbreferenz ist keine Druckfreigabe.

English quick start

Export QuarkXPress XTG from My Palettes or Colour Reduction. Create a new QuarkXPress project, draw a text box, place the text cursor inside it, then use File → Import. Enable Interpret XPress Tags and use UTF-8. Set the RGB solid-colour source profile to sRGB IEC61966-2.1. Check the imported swatch names and RGB numbers in Edit → Colors. Keep Clarus JSON/the complete reduction job for provenance. Existing names may conflict; validate in an empty project first. Native QuarkXPress import has not yet been tested.
