Farbherkunft sichtbar machen

RC34.11 · Entwicklungsvorschau auf Basis der veröffentlichten RC34.10.

  1. Ein PNG-, JPEG- oder WebP-Bild im Image Picker öffnen.
  2. Unter Colour origin / Farbherkunft die Angaben zur Originaldatei lesen.
  3. Einen Pixel wählen. Jetzt erscheinen Source Colour und zugeordnete ATLAS-Referenz getrennt.
  4. Über Open in Hover → Add to palette übernehmen. Die Herkunft bleibt am einzelnen Source-Datensatz hängen, auch wenn mehrere Quellen dieselbe Referenz haben.
  5. Clarus JSON oder QuarkXPress ZIP · XTG + Source JSON exportieren. Zum Wiederöffnen das Clarus JSON importieren.

Profil vorhanden: Die eingebetteten ICC-Bytes wurden gefunden; Kopf und Taggrenzen wurden geprüft. Profilname und Prüfsumme werden aufgezeichnet. Dies beweist weder ein fachlich richtiges Profil noch eine korrekte Browserumrechnung.

Kein eingebettetes ICC: Ein PNG kann trotzdem sRGB ausdrücklich deklarieren. Andere Farbangaben, etwa EXIF oder PNG-cICP, werden als nicht ausgewertet markiert. Fehlende Profile werden niemals durch eine stillschweigende sRGB-Zuweisung ersetzt.

Verarbeitung: Source Colour bezeichnet weiterhin den sRGB-Wert nach dem Lesen durch den Browser. Dessen konkrete Profilumrechnung oder Ersatzannahme ist nicht beobachtbar. Native Pixelwerte vor dieser Verarbeitung werden hier nicht erfasst.

Ausgabe: Ein Ausgabeprofil gehört zum getrennten Druckauftrag. Es wird nicht aus einem gerade geöffneten Druckfenster in den Source-Datensatz übernommen. RGB-only-Zuordnung, Masterwerte und Referenzidentität ändern sich nicht.

Alte Datensätze bleiben lesbar und zeigen „nicht geprüft“. GIF und unbekannte Formate, fehlende Dekompressionsunterstützung sowie Dateien über 64 MiB erhalten einen offenen Status. ICC-Daten sind auf 16 MiB begrenzt.

Originaldatei aufbewahren: Paletten-JSON enthält aufgezeichnete Angaben und Prüfsummen, keine Originalbild- oder ICC-Dateien. Importierte Angaben werden auf Konsistenz geprüft, ohne die Originaldatei erneut zu untersuchen. Das ist keine Signatur und keine Druckfreigabe.

English

Open a PNG, JPEG or WebP in Image Picker and expand Colour origin. Sample a pixel and add it through Hover to a palette. Export Clarus JSON, or the combined QuarkXPress ZIP, to retain each source's metadata. Embedded ICC presence, an explicit PNG sRGB declaration, missing ICC and invalid/uninspected metadata remain distinct. Browser conversion is not observable. Keep the original image: palette JSON contains metadata, not image or ICC bytes. Output profiles remain in the separate Print job.
