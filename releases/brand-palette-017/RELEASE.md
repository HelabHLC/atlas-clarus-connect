ATLAS Clarus Browser Edition 0.1.7 adds logo review and shared brand palettes for two to eight defined applications. Load a PNG, JPEG or WebP, review the actual source colours, import the output profiles for the intended materials, and set the three tolerances. The project retains the original image with its embedded ICC, the starting assignments and each confirmed choice. German and English are supported.

The public package carries the named profile associations, sources and hashes. Import your own production ICCs locally. The installer verifies the packaged files before switching the IONOS runtime and keeps the previous runtime available for rollback. The physical production result needs a sample.
