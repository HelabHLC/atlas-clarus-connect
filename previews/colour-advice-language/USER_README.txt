ATLAS Clarus Browser Edition + Startup Colour Kit 0.1.5 — Deutsch / English

DEUTSCH
1. ZIP vollständig entpacken und START_HERE.html öffnen.
2. Deutsch oder English wählen. In der Farbberatung kann die Sprache jederzeit gewechselt werden.
3. Der Umschalter gilt für das Startup Colour Kit und die neue Farbberatung der Browser Edition. Die bestehende Browser-Oberfläche bleibt in ihrer bisherigen Sprache.
4. Die gewählte Sprache wird nach Möglichkeit lokal gespeichert. Die Links in START_HERE.html setzen die Sprache ausdrücklich. Projektdateien ändern ihre Farbdaten dadurch nicht.
5. Druckereianfrage, Farbkarte und read-me.txt in der Farbmappe verwenden die aktuelle Sprache. Selbst eingegebene Namen, Materialangaben, Profilnamen und feste Referenzadressen bleiben unverändert.
6. Beim Sprachwechsel bleiben bestätigte Ersatzentscheidungen und vorhandene B/A-Ergebnisse erhalten. Nach dem erneuten Öffnen einer Farbmappe muss B/A wie bisher neu berechnet werden.
7. Die Farbkarte zeigt B und A nebeneinander. Direkte Referenzauswahl wird als solche benannt. Sind alle ursprünglichen Adressen enthalten, ist für Ersatzfarben keine Toleranz erforderlich.

ENGLISH
1. Extract the entire ZIP and open START_HERE.html.
2. Choose Deutsch or English. You can change the language at any time in colour advice.
3. The switch covers Startup Colour Kit and the new colour advice workspace in Browser Edition. The existing Browser interface keeps its previous language.
4. The preference is saved locally where possible. Links in START_HERE.html explicitly select a language. Project colour data is unaffected.
5. The printer inquiry, colour card and dossier read-me.txt use the current language. User-entered names, material descriptions, profile names and fixed reference addresses remain unchanged.
6. Changing language preserves confirmed replacement decisions and current B/A results. As before, reopening a dossier requires a new B/A calculation.
7. The colour card displays B and A side by side. Direct reference selection is identified as such. If all original addresses are present, replacement tolerance is unnecessary.

This is a local preview. Library membership confirms the reference address in a documented list; it does not establish a print approval. Replacement similarity compares stored sRGB colours using CIEDE2000, Lab D65/2°, kL=kC=kH=1. HLC target Lab values are not used. ICC roundtrips are computed previews without paper-white simulation. Check the material, process, profile version and measured approval proof with your printer.
