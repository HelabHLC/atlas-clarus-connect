01 Quick start

  1. Extract the ZIP. Keep the complete folder structure. Do not run the application inside the archive.
  2. Open index.html. Use a current desktop browser. The header should show OFFLINE · LOCAL.
  3. Choose a source. Use Image Picker for an image region or Hover Library for a known reference.
  4. Freeze and save. Add the reference to a palette and export Clarus JSON. Browser storage is not a backup.
  5. Prepare for print. Attach the appropriate CMYK and/or 7CLR profile, record the production metadata and export the handoff JSON.

02 Understand the identity model

The source is resolved to the active PKL master before any production path is prepared. The ATLAS address, atlas_row_id, master RGB and master provenance remain the reference identity. Output profiles create device-specific preparations; they do not rewrite the master.

Observed source

RGB pixels read locally from an image. This is not a spectral measurement.

PKL Full Reference

The frozen colour address and provenance. It does not guarantee reproduction on every device.

4C and ECG paths

Independent profile-bound preparations. Neither path receives device values from the other.

Measured QC

A later physical result may be appended without overwriting the identity.

Validation baseline: 13,283 references · zero-based unique row IDs · master SHA-256 8283ab91b10f89ac758d09ecf5fb4d6343536600a06dd468b1cc1ecf4ec747c4 · A′ v0.4 selection logic unchanged.

03 Use the Image Picker

  1. Load PNG, JPEG, WebP or GIF.
  2. Choose Single pixel or an area mean of 5 × 5, 11 × 11 or 21 × 21 pixels.
  3. Click the intended region and inspect the loupe.
  4. Review ATLAS reference, atlas_row_id, master RGB, HEX and provenance.
  5. Add the result to a palette, open it in the Wheel, create a reference card or prepare it for print.

Boundary: area averaging is not spectral measurement, physical equality, production approval or measured QC.

04 Find references and build palettes

Search the Hover Library by HLC reference, atlas_row_id or HEX. For example: H040_L045_C095, 1382 or #D60000.

  • Each palette can hold up to 64 references.
  • The local workspace can hold up to 50 palettes.
  • Export Clarus JSON after meaningful changes.
  • Use ASE for Adobe and Affinity, GPL for GIMP and Inkscape, token JSON for Figma and CSS custom properties for web projects.

05 Explore without changing identity

The Colour Identity Wheel shows screen contrast, illumination-resilience metadata, ARBE λ* comparison, geometric relationships and tonal families. These tools add context; they do not replace the selected reference.

Append measured QC

Select the immutable target, measure the physical sample outside the bundle, and enter L*, a*, b* plus the instrument or source. RC22 reports ΔE*ab for local review. This is not ΔE00 and is not written into the master.

06 Prepare independent 4C and ECG paths

  1. Name the job and choose the selected reference, active palette or imported handoff.
  2. Attach a printer-class CMYK profile to 4C.
  3. Attach a printer-class 7CLR CMYKOGV profile to ECG.
  4. Record printing condition and substrate.
  5. Select rendering intent and black-point compensation independently.
  6. Create profile-bound data and retain NOT_MEASURED until a real sample is measured.
  7. Export both paths as JSON and export the readable report.

Supported intents: Perceptual, Relative colorimetric, Saturation and Absolute colorimetric. Profiles must be no larger than 16 MiB. Image preview requires both A2B and B2A transforms.

07 Create parallel image previews

The module performs independent local LittleCMS round trips: sRGB → device values → sRGB. Load PNG, JPEG or WebP, or reuse the Image Picker image. The longest side is limited to 1200 pixels.

  • Create both previews together or calculate only one path.
  • Save each before-and-after PNG.
  • Save the matching preview-details JSON with profile hash and settings.

Do not claim: a round-trip preview is not paper-white simulation, a physical print, contract proof, certification or production approval.

09 Troubleshooting

Application does not open correctly
Extract the complete archive again and open index.html inside the intact folder.
A saved palette disappeared
Import the most recent Clarus JSON backup.
An ICC profile is rejected
Use CMYK for 4C or 7CLR CMYKOGV for ECG, below 16 MiB, with valid transforms.
Create both previews is disabled
Load an image and attach compatible profiles to both paths.
The physical print differs
Check press, substrate, calibration, RIP conversion and viewing conditions, then measure the dried sample.

10 Before printer handoff

  • Confirm ATLAS address, atlas_row_id and master SHA-256.
  • Confirm the exact ICC profile and its SHA-256.
  • Record printing condition, substrate, rendering intent and BPC.
  • Preflight the production PDF and inspect all intended separations.
  • Tell the printer not to apply an unintended additional conversion.
  • Measure the dried sample after controlled printing.

Claim boundary: ATLAS Clarus identifies, freezes and documents a reference colour and its preparation paths. Physical claims require controlled printing, documented viewing conditions and measurement.
