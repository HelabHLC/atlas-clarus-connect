## WordPress synchronization

The WordPress manual page uses the `[atlas_clarus_manual]` shortcode. The shortcode fetches the HTML file from the `main` branch, sanitizes the allowed HTML and caches it for fifteen minutes. Updating the HTML file on `main` therefore updates the public manual automatically after cache expiry.

The frozen PKL identity rules and master data are not modified by this documentation mechanism.
