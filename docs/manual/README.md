## Validation boundary

Source logic and reported synthetic camera state tests are distinct from physical browser acceptance. Android-browser and iPhone/Safari camera, orientation, lamp, background/return and real downloads remain pending in the reviewed RC34.5 evidence. A native Android app test is not browser acceptance. Camera RGB is not calibrated measurement; library membership is not production approval. Save camera PNG and selection JSON separately from the complete reduction job: project formats do not automatically embed the camera record.

Documentation changes do not modify the frozen master, assignment logic, libraries, project schemas or release binary checksums.
