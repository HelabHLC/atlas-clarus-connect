# ATLAS Clarus APF Material Bridge v0.1

Manufacturer-neutral identity, status and evidence binding for external
appearance materials.

> ATLAS Clarus APF binds a stable colour identity to external appearance
> materials and preserves the evidence chain from reference to rendered and
> measured appearance.

First-class declarations: MaterialX, OpenPBR JSON, glTF/GLB and PBR texture
sets. Proprietary formats may be connected only through optional adapters.

Validate the complete example:

```bash
python3 validate_apf_material_bridge_v0_1.py examples/apf-material-bridge-v0.1.example.json
```
